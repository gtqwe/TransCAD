# TransCAD
This is a Transformer-based smart contract anomaly detection model.
Our previous research has already been presented at GLOBECOM 2023. Tong Gu, Min Han, Songlin He, et al. Trap Contract Detection in Blockchain with Improved Transformer. In 2023 IEEE Global Communications Conference, pp. 5141-5146.
The dataset can be referenced at: https://xblock.pro/\#/dataset, https://honeybadger.uni.lu/, https://github.com/sujeetc/ScrawlD.
